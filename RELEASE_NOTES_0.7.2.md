# Release notes — pydrlpdid 0.7.2

Version 0.7.2 is the estimator-identity and replication-routing correction
for the formal API introduced in 0.7.0 and the inferential corrections
released in 0.7.1.

## Preserved statistical correction

The cluster-level influence contributions now implement the uncorrected
cluster sandwich stated in the article:

\[
\widehat{\mathrm{Var}}(\widehat\theta)
=
\sum_{c=1}^{G}\widehat\psi_c^2.
\]

Version 0.7.0 multiplied this variance by a CR1 finite-sample factor involving
the dimension of the stacked moment system. Because IPT and DRLPDID-IPT can
represent the same estimator with different nuisance-system dimensions, that
factor made their standard errors depend on the chosen algebraic
representation. Version 0.7.1 removed that factor, and 0.7.2 preserves the
same covariance calculation.

## Regression-adjustment identity

Earlier notebooks labeled `DRLPDID(estimation_method="ra")` as `LPDID-RA`.
Version 0.7.2 removes this ambiguity:

- `LPDID-RA` is generated by `LPDID(target_estimand="ra")` and follows the
  Dube et al. clean-control regression sample;
- `DRLPDID-RA` is generated by `DRLPDID(estimation_method="ra")` and remains
  on the formal common supported stack.

The `LPDID` benchmark now supports multiplier inference based on its native
cluster influence functions. No manually reconstructed standard errors or
bands are used.

## Complete notebooks

The release contains three clean notebooks:

1. `Application_1_Bacon_pydrlpdid_v0.7.2_LOCAL_H19.ipynb`;
2. `Application_2_Dube_and_Formal_Switching_pydrlpdid_v0.7.2.ipynb`;
3. `Monte_Carlo_DRLPDID_pydrlpdid_v0.7.2_FINAL.ipynb`.

They retain the complete tables, diagnostics, CSV/LaTeX exports, and figures,
but write to new 0.7.2 output directories. The
Monte Carlo notebook uses atomic replication-level checkpoints and rejects
checkpoints whose package version, source hash, or settings signature differs
from the current run.
